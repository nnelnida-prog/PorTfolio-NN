Problem-Solving Portfolio

Real-world IT troubleshooting cases, system diagnostics, and root-cause analytics.

Case 1: Windows Setup Error Loop Resolution via Registry Editor

Problem: Encountered a persistent setup error loop ("Windows could not complete the installation") during a clean Windows 11 OS reinstallation on an MSI laptop.

Diagnostic Procedure: Accessed Command Prompt using Shift + F10 and launched Registry Editor (regedit).

Solution: Navigated to HKLM\SYSTEM\Setup\Status\ChildCompletion, modified the value from 1 to 3, and completed bootup.

Case 2: Local DNS Cache Corruption & Web Connectivity Failure

Problem: Web browser failing to load live GitHub Pages deployments despite active Wi-Fi connection.

Solution: Executed ipconfig /flushdns in Command Prompt to clear the DNS resolver cache.
